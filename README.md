# jarvis.si

Client-facing freelance portfolio for Ayushman Singh: apps, web design, Instagram reels, UGC ads and social content. Static single page (`index.html`), no build step.

## Deploy on GitHub Pages
Repo **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.** Site appears at https://imjarvissingh.github.io/jarvis.si/

## Things to fill in
- **Work samples:** edit the `WORK` array near the bottom of `index.html`. Add `img: "assets/yourfile.jpg"` and/or `link: "https://..."` to each item; the "SAMPLE SLOT" badge disappears when `img` is set.
- **Prices:** the Packages section shows `₹ —`; replace with real "from" prices.
- **Testimonials:** replace the three placeholder quotes.
- **Contact:** the form opens an email to ayushmansingh2606@gmail.com; change the address in `index.html` if needed.
